# Agent guidelines

This package is published to npm as `@base2/pretty-print-object` and has
millions of weekly downloads. Treat every release as high impact.

## Releases

- Never run `npm publish`, create a release, push tags, or deploy in any other
  way without explicit approval from the maintainer for that specific release.
- Approval for one release does not carry over to the next.
- Do not push to `master` without asking first.

## Attribution

- Do not add any AI, agent or tool attribution to this repository. This
  includes Claude, Codex, Copilot and any similar assistant.
- This applies to commit messages (including `Co-Authored-By` trailers),
  branch names, pull request titles and descriptions, tags, code, comments,
  documentation and changelog entries.
- Commits are authored by the maintainer only.
